# Manifest-first Package Reader

Neutrino will upgrade Zarf to v0.82.0 in an isolated change, then use a Neutrino-owned Package Reader for remote direct-Zarf packages and UDS bundles. The reader resolves the requested OCI platform to a digest-pinned Package Root, creates a complete verified Package View containing every declared chart and managed values file, and never fetches `images/**` descriptors. A Bundle Inspection fails as a whole if any selected package cannot form its Package View; unsupported layouts fail diagnostically rather than falling back to a full pull.

The reader caches verified descriptor bytes by digest using atomic per-digest publication; `--no-cache` resolves and refreshes a new Package Snapshot without reading cached bytes. OCI digest/size validation is required, while Zarf signature-policy configuration, local archive streaming, and component/chart selectors are deliberately outside this cutover. This is a deliberate boundary: a Zarf-provided selector would reduce direct-package work, but a Neutrino-owned core gives direct Zarf and UDS one selection, cache, and failure model. The migration is gated by unit tests and instrumented-registry tests proving that no embedded image blob is requested.
